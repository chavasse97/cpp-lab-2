## Задание 1 (№3)

### Текст задачи

Дан набор целых чисел с четным количеством элементов. Заполнить вектор V исходными числами, вывести вначале вторую половину элементов вектора V, а затем первую половину (в каждой половине порядок элементов не изменять).

### Алгоритм решения

Вводим вектор, находим середину через итераторы и выводим вектор как требуется

## Задание 2 (№7)

### Текст задачи

Дан вектор V. Вставить после каждого элемента исходного вектора число − 1. Использовать функцию-член insert в цикле с параметром-итератором.
Указание. Организуйте перебор элементов вектора в цикле с параметром-итератором i. Вставку выполняйте впозицию ++i, обязательно присваивая параметру i значение, возвращаемое функцией-членом insert

### Алгоритм решения

Вводится вектор, вызывается функция вставки единиц, которая работает через итераторы

## Задание 3 (№5)

### Текст задачи

Даны списки L1 и L2; список L1 имеет нечетное количество элементов. Переместить средний элемент списка L1 в конец списка L2. Использовать один вызов функции-члена splice

### Алгоритм решения

Обоим спискам присваиваем указатели на начало и конец, находим середину первого списка, затем splice переносит элемент первого списка в другой, перестраивая внутренние указатели
